## Your Platform Version

**v1:** Interactive chat only. No caching, no one-way mode.

**v2:** Added one-way UI, rate limiting, and different request contracts.

**v3:** Added caching, citations required, provider failover, and adapter fallback logging.

Different versions have different capabilities and limitations. Check [Common Issues](./common_issues.md) for version-specific notes.
