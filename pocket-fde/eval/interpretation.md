## Historical core evaluation

These results belong to the original synthetic CLI evaluation, not the current hosted web application. The retained JSON, per-case CSV and summary numbers document the same historical run. Its eight development cases are a small controlled simulation and have been used during refinement.

That run reported owner routing on six of eight cases for the core pipeline and one of eight for the baseline. The baseline lacks the fictional platform knowledge by construction, so the difference does not establish a real-world advantage. The no-gate ablation is the closer comparison because it shares retrieval and reasoning but uses vague historical notes.

Scores use automated reference matching, with any judge-based metrics labeled separately. Simulated handover outcomes are not observations of real people. Token totals are measured model usage for that run, not dollar cost or proof of an ongoing cost-saving ratio. Estimated raw code-context size does not by itself establish paid retrieval/indexing costs or a breakeven incident count.

The current web flow excludes pending learning, supports two selectable retrieval methods, reports actual provider usage, and adds private history and explicit human review. Its retained release checks are listed in the [web evaluation guide](../web/evaluation/README.md). Independent real incidents and matched human studies remain necessary before claiming diagnostic accuracy or collaborative benefit.
